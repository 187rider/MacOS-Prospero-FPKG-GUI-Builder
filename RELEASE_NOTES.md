# Release Notes — Prospero FPKG GUI Builder for macOS 🍎🎮

## [v2.0.0] — 2026-10-04

### 🎮 Interactive Compatibility Fakelibs & Live Staging Engine
- **Dynamic Dependency Checklist**: Real-time scanner parses application executables (`eboot.bin`, `*.prx`, `*.sprx`) and cross-references target SDK requirements to present an interactive module checklist with live staged counters.
- **Clear & Intuitive Status Badges**:
  - `REQUIRED`: Modules imported by the game ELF that are missing on the target firmware SDK.
  - `OPTIONAL`: Auxiliary compatibility modules available for optional staging.
- **One-Click `RST` (Reset) Action**: Restores and stages all detected required compatibility stubs from bundled resources into the project folder (`fakelib/`, `sce_module/`, `sce_sys/about/`).
- **Flexible Live Staging**: Checking or unchecking modules stages or removes stubs on disk in real time with zero UI locking.
- **Silent Background Companion Protection**: Neural microcode models (`k9.psp` for `libScePsml.sprx` MFSR / KPN upscaler) are staged seamlessly in the background and protected from manual UI tampering.

### ⚡ Deep Firmware Backporting Pipeline (FW 3.xx - 5.xx)
- **Automated Target SDK Conversion**: Down-patches binaries to target firmware (e.g., FW 4.00 `0x0400000000000000`) with inlined system calls, dynamic symbol version remaps, and ProcParam adjustments.
- **Hardware AMPR Stream Handling**: Safe bypasses for hardware adaptive media playback and automated cleanup of stale `ampr_emu.index.tmp` preventing cutscene heap allocation crashes.
- **Header Sanitization**: Recovers and repairs truncated ELF section headers generated by third-party dumping tools.

### 🚀 High-Speed I/O & Packaging Performance
- **Optimized Stream Pipeline**: Resolved disk I/O bottlenecks during inner PFS image construction and outer container assembly with buffered streaming and parallel block digest computation.
- **Multi-Core Kraken Compression**: Full multi-threaded block compression utilizing all available Apple Silicon and Intel CPU cores.

### 🔔 User Experience & Audio Feedback
- **Completion Chime**: Native audio notification upon successful package completion.
- **Modernized Result Banner**: Visual success feedback with one-click output directory opening.

### 🧠 Real-World Dataset Training & Comprehensive Compatibility
- **Trained Against 25+ Commercial PS5 Game Backports**: Engine verified across titles covering Unreal Engine 4 & 5, Frostbite, Decima, Luminous, Glacier 2, id Tech, REDengine, EGO, IL2CPP Unity, GIANTS, and RAGE.
- **Expanded Module Routing & Destination-Aware Staging**:
  - `fakelib/`: `libSceAgc.sprx`, `libSceAgcDriver.sprx`, `libSceAmpr.sprx`, `libScePsml.sprx`, `libScePlayGo.sprx`, `libSceVdecCore.native.sprx`, `libSceVdecSavc2.native.sprx`, `libSceVdecShevc.native.sprx`, `libSceAppContent.sprx`, `libSceGameUpdate.sprx`, `libSceNpEntitlementAccess.sprx`, `libkernel.sprx`, `libSceFiber.sprx`.
  - `sce_module/`: `libc.prx`, `libSceNpCppWebApi.prx`, `libSceFontGsm.prx`, `libSceJobManager.prx`, `libScePfs.prx`, `libSceFace.prx`, `libSceFaceTracker.prx`.
  - `sce_sys/about/`: `right.sprx`.
  - `app0/` root: `k9.psp` (companion microcode layer for Unity IL2CPP).
- **Targeted Heuristics & False-Positive Prevention**: Discovered that generic string scans for `libkernel` produce false positives on standard library references; implemented dedicated detection requiring `libkernel_module_info` in entitlement emulation contexts.
- **External Storage & USB Metadata Quarantine**: Automated isolation and filtering of macOS resource fork files (`._*`, `.DS_Store`), filesystem metadata (`.Trashes`, `.fseventsd`, `.Spotlight-V100`, `__MACOSX`), and tool backup artifacts (`.bak`, `.esbak`), preventing outer PFS superblock corruptions and 0x8001001d / 0x8001002b kernel mount errors.
- **Hermetic Testing & Zero Data Exposure**: 100% self-contained unit test suite with all personal paths and external scratch dependencies completely eliminated.

### ⚡ High-Throughput Multi-Core Kraken Compression
- **Parallel Block Encoding (`Parallel.For`)**: Upgraded `CompressedPfsFileWriter` and `ProsperoCompressedPfsFileWriter` from single-threaded sequential execution to fully concurrent multi-threaded block encoding across all CPU cores.
- **Parallel Decompression Pipeline**: Accelerated `CompressedPfsFile.Decompress` and `ProsperoCompressedPfsFile.Decompress` with non-blocking, multi-core chunk decoding.
- **Universal Multi-Core Options Default**: Unlocked multi-core concurrency in `PprPfsKrakenWriteOptions` (`MaxDegreeOfParallelism = Environment.ProcessorCount`), yielding massive speedups on multi-core Apple Silicon and Intel systems when building and unpacking packages.
- **Cross-Platform Cryptographic Compatibility**: Enhanced `ProsperoPfsDigest` to seamlessly utilize `ProsperoSha3` with hardware acceleration and portable fallbacks, ensuring flawless execution on macOS.

## [v1.7.0] — 2026-10-03

### 🛡️ Automatic Package Validation & Integrity Assurance
- **Deep Structural & Integrity Validation Engine (`ProsperoPackageArchive.ValidatePackage`)**: Added comprehensive post-build and on-demand validation verifying FIH headers, outer PFS superblock ICVs (`ProsperoOuterPfsSignature.ComputeSuperblockIcv`), `param.json` consistency, PlayGo metadata, and NAPS layout document plan integrity.
- **Automatic Post-Build Verification**: All builds across CLI, GUI, and API now automatically run the validation engine immediately upon completion (`props.AutoValidate = true`), ensuring corrupt or non-mountable packages fail early with descriptive error diagnostics rather than failing on console mount.
- **PlayGo Region & Mask Auto-Repair**: Resolves cross-region dump inconsistencies (e.g. EU `playgo-chunk.dat` inside US packages) by automatically synchronizing the PlayGo Content ID to match the package Content ID and repairing truncated language chunk masks (`0xFF...FF`).
- **FW 4.xx Down-Patch Synchronization**: Automatically synchronizes `param.json` `sdkVersion` with down-patched `eboot.bin` and enforces `requiredSystemSoftwareVersion = "0x0100000000000000"`, preventing launch rejections on lower PS5 firmware versions.
- **Enhanced CLI & GUI Diagnostics**: `fpkg-cli verify` and GUI Unpack/Verify now display complete container metadata, NAPS span counts, PlayGo status, superblock ICV health, and firmware compatibility warnings.

## [v1.6.0] — 2026-10-02

### 🎯 Native macOS Drag & Drop Integration
- **Objective-C Runtime Swizzling (`MacDragDropBridge`)**: Implemented a native AppKit bridge hooking `-[WKWebView performDragOperation:]` via `libobjc.A.dylib` to bypass WebKit sandbox limitations that stripped local filesystem paths from JavaScript drop events.
- **Direct System Pasteboard Extraction**: Reads real filesystem paths directly from `NSPasteboard` (`[NSURL class]` and `NSFilenamesPboardType`) with cursor position mapping in window coordinates.
- **Universal Drop Zones**: Native drag & drop fully operational for Source Directory (`#input-source`), Output Directory (`#input-output`), Inspect PKG (`#inspect-pkg-path`), Unpack PKG (`#unpack-pkg-path`), and Unpack Output (`#unpack-out-dir`), with visual glow pulse animations and automatic metadata scanning.

### 🧩 Selective Fakelib Auto-Detection & Staging
- **Dynamic Binary Dependency Scanning**: Automatically parses ELF dynamic headers of all game/app executables (`eboot.bin`, `*.prx`, `*.sprx`) to detect imported compatibility modules (`libSceAmpr.sprx`, `libSceAgc.sprx`, `libSceAgcDriver.sprx`, `libScePlayGo.sprx`, `libScePsml.sprx`).
- **Selective Injection**: Only injects the exact fakelib stubs required by the target application rather than unconditionally copying all libraries, preventing runtime conflicts while ensuring firmware compatibility.
- **Clean Lifecycle Management**: Preserves existing user libraries and automatically cleans up temporary staging artifacts post-build.

### 📦 Native Packaging
- **Deterministic Release Binaries**: Rebuilt self-contained native macOS `arm64` ReadyToRun bundle and signed DMG installer.

## [v1.4.0] — 2026-09-30

### 🛡️ Critical Fix: PS5 Kernel Mount & NAPS Layout Validation (`0x8001001d` / `0x8002006d`)
- **Eliminated Consecutive / Empty RunBase Entries**: Resolved a kernel mount failure (`validate_layout: m_eStatus[0x8001001d], m_eSection[0xb], m_index[0x49102]`, `ppfs_ioctl_build_apr_metadata_naps() error=109 (0x6d)`, `sceFsBindPackages() ret = 8002006d`) in `WalkBlocks` (`ProsperoNapsLayoutBuilder.cs`).
- **Ordered RunBase Generation**: Enforced strict `if ... else if` hierarchy so natural block run starts and 16-entry boundary markers take priority over cursor-preserving runs, guaranteeing zero empty runs and ensuring every 16th entry begins with a valid `RunBase`.
- **Restored Complete PKG Engine Source**: Un-ignored `decompiled/LibProsperoPkg.PKG` in `.gitignore` which was previously masked by case-insensitive `*.pkg` pattern matching on macOS APFS filesystems.

## [v1.2.0] — 2026-09-28

### 🚀 Native Apple Silicon (M-Series) Self-Contained Runtime
- **Native Mach-O Binary (`arm64`)**: The application bundle (`LibProsperoPkg.app`) now contains a native Mach-O 64-bit executable compiled specifically for Apple Silicon (M1, M2, M3, M4, Pro, Max, and Ultra).
- **ReadyToRun (R2R) AOT Compilation**: All core libraries, PFS filesystem encoders, Kraken decompression routines, and cryptographic engines are pre-compiled into native ARM64 machine instructions. Cold startup time is instantaneous, and CPU efficiency is maximized with hardware SIMD/NEON acceleration.
- **Zero External Dependencies**: End-users do not need .NET SDK, .NET Runtime, or Homebrew installed. The app is completely self-contained—simply double-click `LibProsperoPkg.app` to run.
- **Automated Native Build Pipeline**: Updated `build-app.sh` to automatically detect host architecture (`arm64` vs `x64`) and assemble the self-contained bundle.

### 🌐 Complete English Localization (Unpack & Verify Tab)
- **UI Markup & Labels**: Fully translated Tab 2 ("Unpack & Verify") into English, including input fields, action buttons (*Quick Verify*, *Unpack*, *Browse*), and the detailed package information table (*Title*, *Content ID*, *Game Version*, *SDK Version*, *System Requirements*, *Languages*, *PlayGo Languages*, *DRM Type*, *Container*, *Content Type*, *Package Segments*, *PKG Size*).
- **Frontend & Backend Logging**: All progress status messages, alert prompts, error messages, and console logs in `app.js` and `AppLogic.cs` are now in standard English.
- **Standardized Number Formatting**: Formatted byte sizes using international units (`KiB`, `MiB`, `GiB`, `TiB`) and comma digit separators.

### 🛠️ UI & Workflow Fixes
- **Cancel Button State Reset**: Fixed an issue where the Cancel button remained stuck or reappeared after a build completed. Implemented `resetBuildButtons()` to ensure button states, icons, and visibility are cleanly restored upon build completion, cancellation, or failure.

## [v1.1.0] — 2026-09-27

### 🎮 Critical Fix: 64-Bit Inode Addressing (Large Game Support)
- **Large Game Kernel Mount Fix**: Resolved a critical defect in inner PFS metadata serialization (`ProsperoPs5InnerMetadata.cs`) where 64-bit `DataOffset` values were truncated to 32 bits due to an erroneous write at offset 100.
- **Full File Extent Support**: Guarantees valid kernel mounting on PS5 firmwares (tested up to FW 11.20) for games of any size (> 4 GiB, 20 GiB, 50 GiB, 100+ GiB).
- **Pre-Flight Extent Validation**: Added checked 64-bit bounds validation verifying `DataOffset + DataSize <= innerPfsImageLength` across all generated inodes before packaging finalizes.

### ⚡ Automatic PS5 Native FSELF Conversion
- **Orbis to Prospero Translation**: Detects legacy PS4/Orbis FSELFs (`0x1D3D154F` / `4F 15 3D 1D`), decompresses them back to pure ELFs, and re-signs them into native PS5 FSELFs (`0xEEF51454` / `54 14 F5 EE`).
- **Section Table Sanitization**: Automatically detects and repairs truncated ELF section header tables from dumping tools.

### 🛡️ Smart Metadata & License Quarantine
- **Firmware Auto-Backporting**: Automatically patches `requiredSystemSoftwareVersion` in `param.json` to FW 1.00 (`0x0100000000000000`) to eliminate `CE-100005-6` and `CE-107880-4` installation errors.
- **Safe License Handling (`SceSysQuarantine`)**: Temporarily stages aside conflicting retail license files (`license.dat`, `license.info`) and stale PlayGo tables during packaging so clean debug RIF licenses are generated, restoring all original files untouched upon completion.
